# Chrome 标签搜索实现计划

1. 创建固定 ID 的 MV3 扩展，监听并同步标签，响应已有标签激活请求，提供连接状态及重连按钮。
2. 实现有长度限制的 Native Messaging 编解码、用户级 IPC 桥接、多连接标签状态及请求确认，后台线程与 Slint UI 回调隔离。
3. 为 Windows/macOS 实现用户级宿主注册，内置并导出扩展文件；设置新增独立安装和状态页。
4. 将 ll 模式接入搜索路由及结果模型，保留推荐与网站标签逻辑，标签打开等待确认，断连后移除过期结果。
5. 完成协议/扩展/交互检查，更新说明，构建 Windows 发布包并验证宿主不初始化 GUI。

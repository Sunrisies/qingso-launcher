# 启动器样式第一版

用户授权先实现参考 Flow Launcher 的跨平台启动器样式，暂不考虑功能。沿用现有 Rust + Slint 工程，无新增业务依赖。

采用统一深色悬浮布局：760 × 386 逻辑像素窗口，内部 720 × 346 面板，16 像素圆角、细边框和阴影。搜索区在顶部，分类条在其下，结果区高度为 162 像素，最多同时显示三条 54 像素结果行。超过三条时自动显示垂直滚动条，底部显示品牌、预览标识和键盘提示。

视觉层次用中性深灰背景、蓝色选中态、浅色标题和灰色说明建立。SVG 图标内嵌项目，避免 emoji 和特殊回车字形的跨平台差异。首条结果固定选中，其他结果显示悬停背景。分类及快捷键只用于展示，列表不随输入变化。

平台分支仅调整字体、快捷键文案以及终端和系统设置名称。Windows 使用 Segoe UI，macOS 使用 Helvetica Neue。两个平台均使用 winit 获取窗口所在屏幕，在原生窗口及实际尺寸就绪后居中，按物理像素及屏幕原点处理缩放和副屏坐标。背景使用实色，系统模糊及振动效果不在本版范围。

输入框支持基础文本输入，关闭按钮及 Esc 支持结束窗口，便于运行预览。搜索、应用启动、分类切换、全局快捷键、列表键盘导航均留待后续工作。

验证方式：Cargo 编译检查和构建，Slint 渲染器截图检查裁切、中文字体、图标和间距。Windows 已完成验证；macOS 需要实际设备验证，不能以平台文案分支代替实机检查。

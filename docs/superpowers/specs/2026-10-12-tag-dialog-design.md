# 标签弹窗

按用户要求，将标签添加 / 编辑表单从设置页移入居中模态弹窗。标签列表卡片扩大到内容区域主体，高度随窗口变化，列表超出可视区域时滚动。

点击右上角添加按钮清空草稿并打开弹窗；编辑行加载当前数据后打开同一个弹窗。保存沿用既有标签校验和原子持久化，成功后关闭并刷新，失败时保留草稿并显示错误。取消、关闭按钮和 Esc 放弃草稿；表单输入框支持 Enter 保存。

弹窗显示遮罩、关闭按钮、字段及操作区，并自动聚焦首个输入框。弹窗打开期间关闭侧栏、列表操作及背景滚动的交互，避免误操作。

实际渲染检查覆盖弹窗和扩展列表。原生交互检查验证添加、编辑、取消、Enter 保存、错误时保持打开和 Escape 关闭。搜索与持久化逻辑保持原实现。

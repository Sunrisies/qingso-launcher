# 低内存渲染

用户反馈轻搜内存约 150～200 MB，要求判断技术限制并降低占用。运行中的发布版测到工作集 274.31 MiB、私有提交内存 207.61 MiB。当前代码采用默认 Winit / FemtoVG 渲染，并在启动时创建设置组件。

对同一个发布二进制执行两次独立冷启动，分别通过 SLINT_BACKEND=winit-femtovg 和 winit-software 选择渲染器，每次启动 3 秒后测量：

| 模式 | 工作集 MiB | 私有提交 MiB | 累计 CPU 秒 |
| --- | ---: | ---: | ---: |
| FemtoVG | 267.69 | 210.75 | 1.08 |
| 软件渲染 | 72.46 | 38.95 | 0.23 |

私有提交内存减少约 81.52%，主要差异由渲染路径引起。这些是本机同场景测量，不能作为其他机器或长时间使用后的固定上限。Windows 工作集包含共享和私有物理页面，私有提交内存与任务管理器某些内存列存在口径差异。

默认渲染器改为 software，保留已编译的 GPU 渲染器。QINGSO_RENDERER 可显式选择 femtovg 或 software，也尊重已有 SLINT_BACKEND 参数。没有使用工作集强制裁剪来改变任务管理器显示值，没有删减托盘、快捷键或无障碍功能。

验证包括软件渲染的搜索框和弹窗截图、原生键盘及隐藏 / 显示交互检查、设置和快捷键检查、搜索与弹窗检查、严格 Clippy 检查。macOS 仍需实机验证。

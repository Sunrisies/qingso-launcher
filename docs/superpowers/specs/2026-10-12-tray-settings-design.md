# 系统托盘与设置

用户要求托盘包含打开设置、打开搜索框和退出，并在独立设置窗口中记录软件信息、修改快捷键。采用 Slint 内置 SystemTrayIcon 和原生 Menu，无额外托盘库依赖。

主线程创建并保持托盘组件；托盘点击和“打开搜索框”调用已有显示及聚焦逻辑，“打开设置”显示持续复用的 SettingsWindow，“退出”终止后台事件循环并释放快捷键及单实例资源。搜索框保持失焦隐藏，设置窗口使用普通窗口，关闭只隐藏。Windows 继续跳过任务栏，macOS 保持 Accessory 激活策略。

设置窗口采用深色软件信息卡片和快捷键卡片。软件名称、Cargo 软件版本、平台 / 架构和配置路径来自当前运行环境。快捷键编辑使用文本输入，给出 Alt+Space、Ctrl+Alt+Space 和 macOS Super+Space 示例。

保存流程先验证格式和修饰键，注册新组合，再持久化并解除旧组合。格式、占用和文件错误保留旧注册；成功后更新全局事件处理器所匹配的 ID、搜索框提示和设置页当前值。重复保存相同组合不重复注册。配置使用 UTF-8 hotkey.txt，先写临时文件并同步，再原子替换正式文件。启动优先读取 FLOW_HOTKEY，其次用户保存值，最后默认组合。

验证采用独立临时配置目录，覆盖原生 Windows 托盘消息窗口创建、三个菜单回调、设置聚焦及重复打开、错误路径保护、成功更新及保存、相同组合保存和重新初始化后恢复。渲染截图检查中文、输入框、按钮和信息卡片布局。macOS 仍需实机验证。

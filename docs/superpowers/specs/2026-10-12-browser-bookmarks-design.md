# 浏览器收藏书签搜索

用户确认搜索收藏书签，并要求直接读取本地文件。原扩展连接方案已替换。

参考 Flow Launcher BrowserBookmark 的读取思路，扫描 Chrome 用户数据目录中各个配置文件的 Bookmarks JSON，递归读取 roots 和 children。Windows 默认使用 LOCALAPPDATA/Google/Chrome/User Data；macOS 默认使用 ~/Library/Application Support/Google/Chrome。支持设置自定义数据根目录或单个配置文件目录，留空恢复默认路径。

ll 后接空白进入书签搜索，无关键词显示全部，按标题及网址匹配，忽略大小写，多个词同时匹配。沿用三条可见结果、滚动条、上下键选择和点击/回车打开；在默认浏览器打开收藏网址，不切换现有标签。

启动后后台读取，内存缓存；每两秒检查书签文件大小、更新时间及配置文件变化，仅变化时重新解析，手动刷新立即重新读取。文件写入中暂时解析失败时保留该配置文件的上次有效书签并重试，其他配置文件正常加载。只读浏览器文件，不执行 javascript 书签脚本。

设置页显示读取状态、当前路径、自定义路径和刷新按钮。删除扩展源码、Native Messaging、宿主注册及原标签 IPC。已部署的旧扩展宿主调用会直接退出，不唤起普通窗口。

验证嵌套目录、中文、多个配置文件、无效数据、自动更新、失效目录保存、结果滚动和打开回调；Windows 真实 Chrome 书签只读计数；macOS 需实机验证。

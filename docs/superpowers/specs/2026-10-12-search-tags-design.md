# 可配置网站搜索标签

用户要求在设置中增加可添加的搜索标签，输入 b 空格 内容后回车搜索百度，输入 n 空格 内容后回车搜索 npm。实现网站名称、标签和含 {query} 的网址模板，并支持编辑和删除。

设置窗口新增常规设置 / 搜索标签页签，标签列表和编辑器沿用浅色主题。默认配置为 b → https://www.baidu.com/s?wd={query} 和 n → https://www.npmjs.com/search?q={query}。标签按大小写归一化并校验唯一性，模板限定 http / https 且必须含查询占位符。

设置和搜索窗口共享标签存储。每次修改先校验并原子写入 search-tags.json，再更新内存和模型，失败时保留原配置。首次未找到配置时提供默认标签，保存空列表后保持空列表。配置文件与 hotkey.txt 同目录。

搜索输入按第一个空白分为标签和内容，匹配后显示单条网站搜索动作。按回车或点击动作生成编码后的网址，用默认浏览器打开，成功后隐藏窗口。编码覆盖中文、空格、加号、&、# 等字符，避免把查询内容误解为网址参数。空内容、未知标签和浏览器打开失败提供可见提示。

验证包括生成网址的参数解码检查、标签增删改和重新读取、非法模板及重复标签；原生 UI 检查使用浏览器替身验证真实 Enter 回调和设置回调，避免测试发起实际搜索。设置标签页经实际渲染截图检查，Cargo 构建和严格 Clippy 检查通过。macOS 尚需实机验证默认浏览器和窗口表现。

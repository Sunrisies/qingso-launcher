# 推荐管理与多屏定位

用户已确认：手动管理应用、文件夹和网页推荐，每次唤起在鼠标所在屏幕居中。

设置增加独立推荐管理页，列表支持添加、编辑、删除；添加和编辑使用弹窗。名称、类型、目标保存在 recommendations.json，保存成功立即刷新搜索列表。空输入显示全部推荐，普通输入按名称和目标过滤，已有搜索标签优先处理。点击或回车打开选中目标，失败保留窗口并显示错误。默认推荐只使用存在的本地目标和有效网站，不保留假示例。

Windows 从系统鼠标坐标选择显示器，macOS 从鼠标所在的 Quartz 显示器选择对应 Winit 显示器。窗口移动后再次居中以适应 DPI 变化。保留三条可见结果和滚动条。验证配置持久化、失败处理、选择和打开回调、负坐标显示器边界；macOS 运行验证需在 Mac 完成。
